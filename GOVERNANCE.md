# Governance

The project currently has a single maintainer, who has final say on
technical direction, releases and licensing.

* Decisions with architectural impact are recorded as ADRs in
  `docs/architecture/adr/`.
* Changes to dependencies follow the
  [dependency policy](docs/licensing/policy.md): license re-check,
  compatibility test, and a benchmark where relevant.
* Licensing: our code is Apache-2.0 and contributions are under DCO. A CLA
  would only be considered for a concrete need (relicensing, dual licensing)
  and would be announced publicly first.
* As contributors join, this document will define a maintainer group and a
  decision process.
