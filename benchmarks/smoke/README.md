# Non-official benchmark smoke fixture

This is **NON-OFFICIAL INFRASTRUCTURE SMOKE** data. It proves that the
benchmark harness can execute a RAW adapter and a production-task BOUNDED
adapter, materialize identical immutable bases, hide the oracle, evaluate the
final candidate independently, persist results, and render a paired report.

It is not a model benchmark, an OpenCode comparison, or evidence that
BoundedCode improves software-engineering outcomes. The deterministic worker
is selected only because this suite has `official: false` and
`smoke: true`.
